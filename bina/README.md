# بینا (Bina) — پلاتفۆرمی نیشتیمانی

پرۆژەی نوێی **بینا**: پلاتفۆرمێکی یەکگرتووی نیشتیمانی بۆ ڤیدیۆ، مۆسیقا، فێرکاری،
کتێبخانە، یاری و میدیای کوردی — لەسەر بنەمای ئەو نەخشەیەی لە `docs/blueprint/` نووسراوە.

> ئەمە لە سفرەوە دروست دەکرێت، **خاڵ بە خاڵ و هێواش**. ئەمە **هەنگاوی ١** ـە: بناغەی وێب.

---

## ئەوەی ئێستا هەیە (هەنگاوی ١)

- 🎨 ڕووکاری وێب بە **Next.js + React + TypeScript + Tailwind**
- 🌐 بە زمانی **کوردی سۆرانی** و **ڕاست‌بۆ‌چەپ (RTL)**
- 🧭 شریتی کاتێگۆریەکان (فیلم، مۆسیقا، منداڵان، یاری، وەرزش، ئیسلامی، هەواڵ، پۆدکاست، کتێبخانە)
- 🏠 پەڕەی سەرەکی بە ستایلی یوتیوب/فەیسبووک (داتای نمونەیی)

> تێبینی: داتاکان ئێستا **نمونەیین**. لە هەنگاوەکانی داهاتوودا API و داتابەیسی ڕاستەقینە
> زیاد دەکرێن، پاشان کاتێگۆریە تایبەتەکان، ئەپڵۆد، لۆگین، دۆبلاژ، هتد.

---

## چۆن ڕەنی بکەیت

پێویستت بە **Docker Desktop** هەیە (هەمان ئەوەی پێشتر دامەزراندت).

١. تێرمیناڵ بکەرەوە و بڕۆ ناو فۆڵدەری `bina`:
```
cd bina
```

٢. ڕەنی بکە (جارەکەی یەکەم چەند خولەک دەخایەنێت — npm install دەکات):
```
docker compose up --build
```

٣. لە وێبگەڕ بڕۆ بۆ:
```
http://localhost:3000
```

⏹️ بۆ وەستاندن: `Ctrl + C`، یان `docker compose down`.
